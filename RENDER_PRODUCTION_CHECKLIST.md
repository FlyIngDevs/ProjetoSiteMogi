# Render Production Checklist

## Render service

- `Root Directory`: `backend`
- `Build Command`: `pip install -r requirements.txt && python diagnose.py`
- `Start Command`: `python run.py`
- `Health Check Path`: `/health`

## Required environment variables

- `DATABASE_URL` from Render PostgreSQL
- `SECRET_KEY` generated by Render
- `UPLOAD_DIR=/var/data/uploads`
- `SMTP_HOST=smtp.gmail.com`
- `SMTP_PORT=587`
- `SMTP_USERNAME=contatoflyingmm@gmail.com`
- `SMTP_PASSWORD=<gmail app password>`
- `SMTP_FROM_EMAIL=contatoflyingmm@gmail.com`
- `SMTP_FROM_NAME=Flying MM`
- `SMTP_USE_TLS=true`
- `SMTP_USE_SSL=false`
- `DEBUG=false`

## Required infrastructure

- PostgreSQL database attached to the web service
- Persistent disk mounted at `/var/data`

## First deploy checks

1. Open `/health` and confirm `{"status":"healthy"}`.
2. Open `/docs` and confirm the API loads.
3. Open `/api/annotators/` and confirm the endpoint responds.
4. Open `/pages/admin.html` and confirm the admin UI loads.
5. Create a test record in admin and refresh the home page.
6. Submit a test job application and confirm the email is delivered.

## Important note

`python run.py` now fails fast if the database connection is broken. This is intentional for production so Render does not keep a half-working service online.
